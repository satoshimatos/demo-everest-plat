# demo-everest-plat
Exported version of the demo game I made for the Everest Plat challenge

# How to download
You may clone the repository using git. Alternatively, you may click on `<> Code` (green button on top of this page) and click `Download ZIP`.

# How to run
Simply run `EverestChallenge.exe` on your Windows device. If, for any reason, you need the console activated, run `EverestChallenge.console.exe` instead.

# Controls
- A -> left
- D -> right
- Space -> jump
- Left click -> attack
